# AI — Retrieve

When answering questions from the Second Brain:

1. Search for direct evidence first.
2. Prefer recent and active notes when the question is current.
3. Distinguish facts, personal interpretation, and AI inference.
4. Surface contradictions instead of hiding them.
5. Include relevant note links using `[[wikilinks]]`.
6. If evidence is missing, say so clearly.

A useful answer should synthesize the knowledge base rather than merely list matching notes.

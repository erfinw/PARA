# Someday / Maybe

Ideas that are interesting but have not earned active-project status.

## Current Pipeline

- ClinicUp
- Growth OS
- Future AI/business ideas

## Promotion Rule

An idea becomes an active Project only when there is:

1. A committed outcome.
2. A reason to do it now.
3. Allocated time/resources.
4. A next action.
5. A defined validation or success measure.

The purpose of this list is to protect focus while preserving good ideas.

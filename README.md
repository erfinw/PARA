# PARA — Erfin's Second Brain

An Obsidian-compatible, Git-backed personal knowledge system using PARA as its core organizing method.

## Structure

- `00_Inbox` — unprocessed capture
- `01_Projects` — outcomes with a defined finish line
- `02_Areas` — ongoing responsibilities
- `03_Resources` — reusable knowledge and reference material
- `04_Archives` — inactive material
- `05_Daily` — daily notes and reflection
- `06_People` — people and relationship context
- `07_Templates` — reusable note templates
- `99_System` — dashboards, AI instructions, rules, and reviews

## Principle

Capture first. Organize second. Connect third. Reflect regularly. The system exists to improve thinking and decision quality, not to maximize the number of notes.
